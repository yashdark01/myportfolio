# RAG Frontend — Enterprise Document Querying UI

React frontend for **RAG-based sustainability document querying** — built as part of enterprise ESG platform work at Horizon17.

[![Case Study](https://img.shields.io/badge/case_study-read-10b981?style=flat-square)](https://yashpatidar.vercel.app/work/horizon17-esg)

## Features

- Vector search UI for long compliance / sustainability documents
- Notion-style AI editor for report drafting with HITL review
- Chunked document ingestion interface
- LangChain + LangGraph integration patterns

## Context

Built while working as Full Stack Developer at **Horizon17 Technology** on enterprise ESG analytics:

- **40%** faster dashboard loads (SSR + code splitting)
- **45%** backend performance gain (Redis caching)
- **60%** faster sustainability report drafting (AI editor)

> Note: Enterprise client data is not included in this repo. This frontend demonstrates RAG UI patterns only.

## Tech Stack

`React` · `Next.js` · `LangChain` · `LangGraph` · `Tailwind CSS`
