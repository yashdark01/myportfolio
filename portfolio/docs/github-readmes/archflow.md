# Archflow — System Architecture Canvas

In-browser tool for developers to **design, visualize, and share system architectures** — drag-drop nodes, connections, AI assistance, and diagram-as-code support.

[![GitHub](https://img.shields.io/badge/repo-archflow-10b981?style=flat-square)](https://github.com/yashdark01/archflow)
[![Status](https://img.shields.io/badge/status-ongoing-amber?style=flat-square)](#)

## Features

- Canvas-based architecture diagrams with draggable nodes and connections
- Share and visualize system designs in the browser
- AI-assisted diagramming workflows
- Diagram-as-code support for version-friendly exports

## Tech stack

`TypeScript` · `React` · System design · Canvas UI

## Status

**Ongoing** — actively building core canvas, node library, and collaboration flows.
