# GitHub README Templates

Recruiter-friendly README files for your pinned repositories.

## How to use

1. Open the template for each repo below
2. Copy contents to `README.md` in the corresponding GitHub repo
3. Pin these 4 repos on your GitHub profile:
   - `krashaq-agritech`
   - `krashaq-backend`
   - `RAG-Frontend`
   - `spotify`

## Quick copy commands

```bash
# From portfolio repo root — paste into each cloned repo
cp docs/github-readmes/krashaq-agritech.md ~/krashaq-agritech/README.md
cp docs/github-readmes/krashaq-backend.md ~/krashaq-backend/README.md
cp docs/github-readmes/spotify.md ~/spotify/README.md
cp docs/github-readmes/RAG-Frontend.md ~/RAG-Frontend/README.md
```
